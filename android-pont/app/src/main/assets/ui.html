Enceintes appairées
Active les enceintes à connecter automatiquement : dès que l’une d’elles est allumée, elle se connecte, dans l’ordre de la liste (1 avant 2…). Si tu déconnectes une enceinte, la suivante allumée prend le relais ; celle déconnectée ne revient pas toute seule tant que tu ne la reconnectes pas. Une nouvelle enceinte s’appaire d’abord dans les réglages Bluetooth du téléphone.

Appareils clonés
Ajouter un clonage
Le clone reprend tel quel l’appareil choisi (mêmes services, mêmes données, octet pour octet) : la montre le voit comme l’appareil d’origine. Données seulement : ce que la montre écrit n’est pas transmis. Un appareil apparaît ici dès qu’App Hike l’a connecté une fois ; son clone démarre quand il est connecté.
